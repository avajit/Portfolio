# 🚀 Avajit's VS Code Portfolio v3

An interactive, responsive portfolio website built with **Next.js 16**, **Tailwind CSS 4**, and **TypeScript**, designed with a full VS Code IDE aesthetic.

---

## ✨ Features

- **VS Code Theme Engine**: Instant theme switching between *VS Code Dark+*, *GitHub Dark*, *Monokai*, *Solarized Dark*, and *Cyberpunk*.
- **Interactive Command Palette (`Ctrl+P`)**: Search across all sections, trigger commands, or jump into easter egg minigames.
- **Embedded Terminal (`Ctrl+\``)**: Execute built-in shell commands like `help`, `skills`, `projects`, `contact`, and `clear`.
- **Avajit's Copilot Panel**: Scripted interactive AI assistant to answer questions about skills, experience, and projects.
- **Dino Runner Minigame 🦖**: Built-in canvas game playable directly inside the IDE.
- **Scroll-Synced Editor Tabs**: Active tabs highlight and update as you scroll through portfolio sections.
- **Fully Responsive**: Mobile drawer support for Copilot panel, compact titlebar menus, and mobile-friendly sidebar navigation.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4 & Custom CSS variables
- **Language**: TypeScript
- **Icons**: Lucide React / VS Code Web Icons

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/avajit/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
